## UvsU
 
### Overview
A simple 2D puzzle platformer inspired by the idea: "What if you can fight against yourself?", UvsU is a puzzle game project building in Unity with an aiming at improving development skills and learning about puzzle design through the creation of a unique gameplay experience centered around interacting with past versions of the player.

#### Key features
- 2D platformer controller
- Simulation of player clone using command pattern
- Interactable object (switch, door, trap,...)
- Difficulty increase as player run through level
